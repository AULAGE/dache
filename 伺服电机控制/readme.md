# 升降轴下位机（STM32F103C8T6）

STM32 给伺服或步进驱动器发 **脉冲 + 方向** 信号，树莓派（或电脑串口助手）通过串口发文本指令控制。

- 行程 **0 ~ 50cm**，0 = 最下端
- **上电时滑台必须在最下端**，上电后位置自动为 0
- 默认速度 8cm/s，加速度 50cm/s²，走满 50cm 约 6.5 秒

## 接线

| STM32 | 接到 | 说明 |
|---|---|---|
| PA6 | 驱动器 PUL+ | 脉冲（PUL- 接 GND） |
| PA5 | 驱动器 DIR+ | 方向（DIR- 接 GND） |
| PA9 (TX) | 树莓派 GPIO15 / RXD（物理脚 10） | 交叉连接 |
| PA10 (RX) | 树莓派 GPIO14 / TXD（物理脚 8） | 交叉连接 |
| GND | 树莓派 GND（物理脚 6）、驱动器信号地 | **必须共地** |

树莓派和 STM32 都是 3.3V 电平，可以直接连。驱动器如果要求 5V/24V 信号输入，需要加电平转换或串限流电阻。

**驱动器每圈脉冲数要设成 1600**，或者改 `stepper.h` 里的 `PULSES_PER_REV`。

## 串口协议

115200 8N1。每条指令一行，用 `\n`、`\r` 或 `\r\n` 结尾，不区分大小写，数字可以带 2 位小数。

| 指令 | 作用 | 回复 |
|---|---|---|
| `A 30` | 走到**绝对位置** 30cm（重复发 `A 30` 不会再动） | `OK GO 30.00`，到位后 `DONE 30.00` |
| `R 5` / `R -2.5` | **相对移动**，正数向上，超出行程会截断 | `OK GO 35.00`（截断时加 ` CLAMP`），然后 `DONE ...` |
| `1 10` / `0 10` | 旧格式：向上 / 向下 10cm | 同 `R` |
| `M 20` | 只设目标，不运动 | `OK M 20.00` |
| `G` | 走到 M 设定的目标 | 同 `A` |
| `S` | 减速停（8cm/s 时约滑行 0.6cm） | `OK S`，然后 `DONE 12.34 STOP` |
| `E` | 立即停（最多再走完当前这一个脉冲） | `OK E`，然后 `DONE 12.34 STOP` |
| `P` | 查询位置 | `POS 12.34 IDLE` / `POS 12.34 MOVING TGT 30.00` / `POS 0.00 UNHOMED` |
| `Z` / `Z 25` | 声明当前位置为 0cm / 25cm（停机时） | `OK Z 0.00` |
| `V` / `V 10` | 查询 / 设置速度 cm/s（0.5~20），**运动中也立即平滑生效** | `OK V 10.00` |
| `?` | 帮助 | |

### 运动中可以随时发新指令

- `A`、`R`、`G`、`1/0` 在运动中都能发，不会 BUSY，目标会平滑切换：同方向直接加速或减速，反方向先减速再掉头
- **运动中连续发 `R` 会累加**：连发三次 `R 10` = 在当前目标的基础上再往上 30cm
- 运动中发 `S` 后再发 `R 5`，是从停止点再往上 5cm

**约定**：电机**最终停下**时发一次 `DONE <位置>`。运动中改了几次目标，只在最后停下时回一次 DONE；空闲时发的目标就是当前位置，会立即回 DONE。树莓派发完运动指令后等 `DONE` 就行。

错误回复：

| 回复 | 原因 |
|---|---|
| `ERR BUSY` | 运动中发了 `Z`，先停下 |
| `ERR RANGE 0.00-50.00` | 超出行程 |
| `ERR LIMIT` | 已经在边界，还要往外走 |
| `ERR UNHOMED` | 位置未知，先发 `Z` |
| `ERR FORMAT` / `ERR UNKNOWN` / `ERR TOOLONG` | 格式错误 / 未知指令 / 一行太长 |

## 上电与复位

启动时会打印一行，例如 `READY MAX 50.00 RST POR`。

- `RST POR`：断电后重新上电，认为在最下端，可以直接运动
- `RST PIN` / `SFT` / `WDG`：按了复位键、下载程序或看门狗复位，**滑台可能不在最下端**，行尾带 `UNHOMED`，运动指令会被拒绝。
  确认位置后发 `Z`（在最下端）或 `Z 25`（已知在 25cm）再继续。
  只想调试、不需要这层保护的话，把 `main.c` 的 `HOMED_ON_ANY_RESET` 改成 1。

树莓派收到 `READY` 就说明下位机复位过，应该重新确认位置。

## 树莓派端

1. `sudo raspi-config` → Interface Options → Serial Port：登录 shell **选否**，串口硬件 **选是**，然后重启
2. `pip install pyserial`
3. 用 `raspberrypi/lift.py`：

```python
from lift import Lift
lift = Lift("/dev/serial0")      # USB 转 TTL 用 "/dev/ttyUSB0"
lift.move_to(20)                 # 走到 20cm，阻塞到 DONE，返回 (位置, 是否被打断)
lift.move_by(-5)                 # 向下 5cm
lift.move_by(10, wait=False)     # 不等待，马上返回
lift.move_by(10, wait=False)     # 运动中再加 10cm（累加）
lift.wait_done()                 # 等最终停下
lift.speed(12)                   # 改速度（运动中也生效）
print(lift.position())           # (15.0, 'IDLE')
lift.stop()                      # 减速停
```

## 参数（`APP/stepper/stepper.h`）

| 宏 | 默认 | 含义 |
|---|---|---|
| `PULSES_PER_REV` | 1600 | 驱动器每圈脉冲数 |
| `LEAD_MM` | 70 | 每圈移动距离（mm） |
| `MAX_POS_CM` | 50 | 最大行程 |
| `DIR_UP_LEVEL` | 1 | 方向反了改成 0 |
| `DEFAULT_SPEED_CM100` | 800 | 上电默认速度（0.01cm/s） |
| `MAX_SPEED_CM100` | 2000 | V 指令上限 |
| `START_HZ` | 400 | 起跳频率 |
| `ACCEL_CM_S2` | 50 | 加速度 / 减速度 |

1 个脉冲 ≈ 0.044mm，位置分辨率 0.01cm。

## 实现要点

- TIM3 PWM2 模式：每个脉冲先低后高，更新事件时回到低电平；空闲时强制输出低电平，停机时 PUL 不会残留高电平
- 一次更新中断 = 一个完整脉冲，位置计数和实际脉冲严格一致；`E` 立即停也不会丢计数
- 运动规划按"跟踪目标"做：每个脉冲根据离目标还有几步、当前速度，决定加速、匀速还是减速（恒加速度，f² 每步加减 2a）。目标可以随时改，目标跑到身后时先减速到起跳频率，再在两个脉冲之间换方向（DIR 建立时间 ≥ 1.25ms）
- 行程保护有两层：主程序把目标限制在 0~50cm；中断里位置一旦到边界就禁止继续往外走
- 串口接收用 256 字节环形缓冲，主循环拆行，连发指令不丢
- 看门狗约 2s
