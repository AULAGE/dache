# 世界模型原型（任务 14，**合成数据**）

论文方案 v2（`docs/论文研究方案.md`）第 3.2 节"动作条件的物体中心世界模型"的最小实现，
在**合成的腕部相机画面**上把训练流程跑通，回答：

- **H1**：只给"命令历史 + 图像"，模型的隐状态能不能线性解码出**真实舵机角**（含回差、死区），比"命令积分"准多少？
- **H2**：不给任何标注，模型能不能把画面分成"自身（爪子）"和"世界（物块）"？

所有结论只在合成数据上成立，**没有用真机图像**。结果和讨论见 `docs/cloud_tasks/results/14_报告.md`。

## 怎么跑

```bash
cd raspberrypi/grasp
pip install -r research/worldmodel/requirements.txt     # torch、numpy（树莓派上不需要）
python3 research/worldmodel/dataset.py                  # 生成 8 条序列，存预览图 results/preview.png
python3 research/worldmodel/train.py --quick            # 10 分钟内（4 核 CPU）：4 个变体各训约 1.8 分钟 + 评估
python3 research/worldmodel/train.py                    # 完整：4 个变体各 15 分钟，约 1.1 小时
python3 research/worldmodel/train.py --variants full,cmdonly --minutes 30 --seed 1   # 自选
```

有 GPU 自动用（`cuda`）；GPU 上可以把 `--batch`、`--minutes`、`--n-train` 调大。
输出都在 `results/`：`train_<模式>.log`、`results_<模式>.md/.json`、`<模式>_<变体>.pt`（约 0.2MB）、
`slots_<模式>_<变体>.png`（3 条测试序列：输入 / 真实掩膜 / 槽位分割，颜色越暗 = w 越小 = 模型认为越像"自身"）。
数据集按种子重新生成（几秒），不存盘。固定种子可复现（同一台机器、同样的线程数；不同 CPU 的浮点顺序可能有微小差别）。

## 文件

| 文件 | 内容 |
|---|---|
| `render.py` | numpy 2D 渲染器：物块（解析抗锯齿，亚像素位置）、固定在画面左侧中间的爪子脚（张 / 合两种形态，最上层、会遮挡物块）、随相机移动的世界背景纹理（墙 / 台面分界）、光照增益和色调、像素噪声、另一个物块、独立乱动的"手" |
| `dataset.py` | 自主探索策略（不看画面）生成序列：底座随机游走（35% 换向）、升降轴、爪子张合；执行器用 `research/sim_world.py` 的 `play()`（死区 + 回差，和 `sim.SimArm._servo_base` 同一规则），回差 / 死区范围用 `sim_world.CAR_RANGES`，底座再乘 0.5~2 倍 |
| `model.py` | 编码器 + Slot Attention（K=4）+ 迟滞记忆 GRU + 动作条件动力学（自身/世界分离先验）+ 空间广播解码器；4 个变体 |
| `train.py` | 训练（按时间预算）+ 调用评估 + 写结果表 |
| `eval.py` | H1 线性探针（岭回归）、H2 掩膜 IoU、槽位可视化 |

## 模型（`model.py`）

```
 o_t ─CNN─► 特征图 ─Slot Attention（初值 = 上一步预测的槽位）─► 槽位 (z_k, p_k)，p_k = 注意力质心
 [u_t, 槽位位置 p_t] ─迟滞记忆 GRU─► h_{t+1} ─线性─► c_{t+1}（相机位姿，画面坐标）
 动力学：p̂_{t+1,k} = p_{t,k} + w_k·(c_{t+1} − c_t)     w_k = sigmoid(MLP(z_k))：0 = 自身（不动），1 = 世界
         ẑ_{t+1,k} = z_{t,k} + MLP(z_k, u_t)
 解码：逐像素 MLP，输入 z_k + "像素位置 − p_k" 的傅里叶特征 → RGB + alpha，softmax 合成
 损失：重建 o_t + 预测 o_{t+1}（只用 ẑ、p̂）+ 0.1 × 分离正则（紧凑槽位的观测位移 = w·Δc）
```

- **h 就是学出来的"本体感知"**：训练时没有任何角度标注；c 是 h 的线性函数，只能通过"世界槽位怎么移动"学到
- 变体：`full` 完整；`noprior` 无分离先验（每个槽位的位移由 MLP(z, h_t, h_{t+1}, u) 自由给出）；
  `nogru` 无 GRU（h = MLP(当前命令, 当前槽位位置)）；`cmdonly` GRU 只看命令历史、不看画面
- 评估另加两条不用学习的基线：命令积分（θ̂ = 命令）、方向记忆规则（θ̂ = 命令 − k·上次转动方向，k 在训练集上拟合），
  和一条对照：同样初始权重、**未训练**的模型（随机 GRU 本身就能记住命令历史，探针在它上面解出的部分不能算"学到的"）

## 评估（`eval.py`）

- **H1**：冻结模型，取 h_t，岭回归探针（只在训练序列上拟合）预测"真实输出 − 命令"，θ̂ = 命令 + 探针输出；
  报告测试集底座 / 升降的平均绝对误差，按底座回差分 4 组，以及"回差方向识别率"（|残差| > 0.25° 的帧，残差符号判断对的比例）
- **H2**：解码器的槽位掩膜（argmax，32×32）和真实掩膜（下采样）的 IoU：
  爪子 / 物块的最佳匹配 IoU；不看真值自动判"哪个槽位是自身"（按 w 最小；或按整段序列质心位移最小、排除铺满全图的背景）
  后，那个槽位和爪子的 IoU；判别正确率

## 换成真机图像（任务 12 的数据集）要改哪里

任务 12 会产出 `dataset.csv`（图像路径、树莓派时间、之前 / 之后最近的动作命令、机械臂各舵机命令脉宽、升降轴高度、抓取结果）
和 K230 存的 JPEG（约 320×180）。要改的地方：

1. **数据加载**：新写 `real_dataset.py`，按 `dataset.csv` 把相邻两次动作之间、画面静止后的那张图取出来，缩放 / 裁成 64×64（或 96×96，
   保持宽高比可以裁中间），输出和 `make_dataset()` 一样的字典：`obs [N, T+1, H, W, 3] uint8`、`u [N, T, 5]`
   （底座命令换算成度：`(脉宽 − BASE_CENTER) / BASE_US_PER_DEG`；升降用 cm；爪子用 CLAW_CLOSE / OPEN 判断）。
   没有真值时 `true` / `mask` 可以先填 NaN，只训练不评估
2. **序列切分**：按抓取回合（`episode`）切，回合内连续动作组成一条序列；中间丢帧 / 时钟对不上的地方断开
3. **动作特征 `U_DIM`**：真机还有 2~5 号舵机（伸出 / 抬起姿态），相机位姿不只由底座和升降决定 → 动作特征加上各舵机命令，
   或者只用"观察姿态下"的片段（对准阶段，和合成数据一样只有底座 + 升降）
4. **评估真值**：H1 要电位器 ADC（论文方案 3.5 节）；H2 要人工标几十张爪子 / 物块掩膜（或用任务 10 的忽略区域当爪子掩膜的近似）
5. **超参数**：真机画面背景复杂、物块更小（真机视场每度不到 1 像素，见报告"和真机的差别"），K 可能要 5~6、分辨率要 96 以上、
   需要 GPU
