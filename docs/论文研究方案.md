# 研究方案 v2：无本体感知机器人的自监督具身世界模型

> 题目（暂定）：**Learning to Feel Without Sensors: Self-Supervised Embodied World Models for Proprioception-Free Low-Cost Mobile Manipulators**
> （无传感器的"感觉"：面向无本体感知低成本移动机械臂的自监督具身世界模型）

## 1. 问题：具身智能默认机器人"知道自己的身体"，低成本机器人不知道

现在的具身智能方法 —— 模仿学习（ACT、Diffusion Policy）、视觉-语言-动作模型（RT-2、OpenVLA、π0 一类）、
世界模型（Dreamer、TD-MPC 一类）—— **几乎都把关节角度（本体感知）当作输入**，并默认动作执行是准确的。

但大量真实的低成本机器人（教学、助老、农业、物流里的 PWM 舵机臂）：
1. **没有关节反馈**：发了命令，不知道实际到了哪；
2. **执行器有迟滞**：回差、死区 → 同样的命令，结果取决于历史（本车实测：命令 +4.8°，实际只修正约 1.6°）；
3. **眼在手上、看得到自己**：爪子在画面里，会被当成目标（本车：跟踪器锁住爪子脚）、会遮挡目标（本车：落点偏右 4mm）。

**这些机器人用不了现有的具身智能方法**：没有本体感知输入，模仿学习的策略没法训练；世界模型学不到执行器的迟滞；视觉模型分不清自己和环境。

**研究问题**：能不能让一台没有任何关节传感器的低成本机器人，**只靠自己的动作和腕部相机**，自监督地学会
（a）自己身体的状态（视觉本体感知）、（b）自己执行器的真实动力学（含迟滞）、（c）分清"自己"和"世界"，
并用学到的世界模型完成精准抓取？

## 2. 核心思想

> **动作是唯一可信的信号**：机器人知道自己"发了什么命令"，画面里"什么跟着命令动、怎么动"，就是学习身体和世界的全部监督。

- 画面里**跟相机固连**的东西（爪子）= 自己的身体；
- 跟着命令按**可预测规律**移动的东西 = 环境里的物体，规律的偏差 = 执行器的迟滞；
- 抓取成败 = 稀疏奖励。

把这三条做成**深度世界模型的结构先验**，用机器人**自主探索**收集的无标注数据训练。

## 3. 方法

### 3.1 数据：自主探索 + 脚本专家，全程无人工标注
- **自主探索**：机器人在工作区里随机 / 好奇心驱动地动底座、升降轴、机械臂，记录 (图像 o_t, 命令 u_t, o_{t+1})
- **脚本专家**：现有视觉伺服抓取系统（本仓库 `task.py`）本身就是一个"会抓的专家"，它的每次抓取轨迹 + 成败都是带奖励的数据
- 规模估计：每秒约 1 个动作，**10 小时 ≈ 3.6 万条转移**；比赛训练期间顺带采集
- 数据集本身是贡献：**首个无本体感知、带执行器迟滞的低成本移动操作数据集**（需文献确认），开源

### 3.2 模型：动作条件的物体中心世界模型（Action-Conditioned Object-Centric World Model）
```
 o_t ──编码器──► 槽位（slots）s_t^1..K ──┐
                                        ├─► 动力学 f(s_t, h_t, u_t) ──► s_{t+1} 预测 ──► 解码/对比损失
 u_{t-H..t} ──迟滞记忆 GRU──► h_t ───────┘            ▲
                                                     └─ 自身/世界分离先验
```
1. **物体中心编码**（Slot Attention 类）：把画面分解成 K 个槽位
2. **自身/世界分离先验**（v1 思想的深度化）：
   - 自身槽位：约束为与相机固连（预测位移 ≈ 0）
   - 世界槽位：位移必须由"相机运动"解释，相机运动 = 学到的执行器模型(u 的历史)
   - 训练中自动分出"爪子"和"物块"，**不需要任何标注**
3. **迟滞记忆 → 视觉本体感知**：用 GRU 处理命令历史 u_{t-H..t}，隐状态 h_t 编码"执行器实际处在哪"（回差的方向记忆、死区）。
   **h_t 就是学出来的本体感知**；评估时用低成本真值（见 3.5）检验 h_t 能否线性解码出真实关节角
4. **奖励头**：从 (s_t, h_t) 预测抓取成功概率
5. **遮挡感知**：物块槽位在被爪子槽位遮挡时，由动力学的时序一致性补全中心（解决偏右）

### 3.3 决策：在学到的世界模型里规划
- 短视距模型预测控制（CEM / MPPI）在隐空间里搜索 u 序列，最大化抓取成功概率；
- 或蒸馏成小策略网络，**部署在边缘**（K230 NPU 跑编码器 + 树莓派跑规划/策略）
- 和脚本专家对比：成功率、步数、对迟滞的鲁棒性

### 3.4 v1 概率模型的位置
- 作为**轻量基线**（无深度学习、可解释）
- 作为世界模型的**初始化 / 正则**（物理先验 vs 纯数据驱动的消融）

### 3.5 低成本真值（只用于评估，不用于训练）
- LDX-218 舵机内部有电位器：**引一根线到 ADC**（例如升降轴那块 STM32 的空闲 ADC 脚）读真实角度，成本几块钱
- 外部手机俯拍 + 坐标纸：落点偏差
- 这样就能定量回答"学到的视觉本体感知有多准"

## 4. 研究假设与实验

| 假设 | 实验 | 指标 | 基线 |
|---|---|---|---|
| **H1** 无本体感知也能学出身体状态 | 从 h_t 解码真实关节角 | 角度误差（°）、对回差方向的识别率 | 开环命令积分；v1 迟滞辨识 |
| **H2** 自身/世界自动分离 | 爪子、物块、干扰物（另一个方块、人手） | 分割 IoU、自身误锁率 | 原 YOLO 跟踪；手工忽略区域；DIJE 类雅可比自识别；无分离先验的世界模型 |
| **H3** 世界模型规划优于脚本专家 | 9 位置 × 多物体 × 迟滞大小（人为加大回差：舵机松一点 / 软件注入） | 真实抓取成功率、步数、用时 | 脚本视觉伺服（现系统）；ACT / Diffusion Policy（用脚本专家数据训练，**无本体感知输入**）；Dreamer / TD-MPC 类（无结构先验） |
| **H4** 数据效率 | 训练数据 1h / 3h / 10h | 成功率随数据量 | 同上 |
| **泛化** | 新物体、新光照、**换爪子**、**换一台不同的低成本臂**（如 SO-100 类开源臂，去掉编码器读数） | 零样本 / 少量微调成功率 | — |
| **消融** | 去掉迟滞记忆 / 分离先验 / 物理先验 / 奖励头 | 全部指标 | — |

统计：每种条件 ≥ 30 次真机试验；Wilson 置信区间；配对比较 McNemar；连续量 Wilcoxon。

## 5. 和已有工作的区别（初步）

| 方向 | 已有工作（初步检索 / 常识，需要核实） | 我们的区别 |
|---|---|---|
| 视觉-语言-动作、模仿学习 | RT-2、OpenVLA、π0、ACT、Diffusion Policy | 都依赖本体感知和准确执行；我们研究**没有本体感知 + 迟滞执行器** |
| 世界模型 | Dreamer、TD-MPC、视频预测类 | 通常有本体感知或仿真；我们加**自身/世界分离**和**迟滞记忆**的结构先验，真机自监督 |
| 机器人自我模型 | Lipson 组的视觉自我建模；DIJE（arXiv 2507.00446） | 他们多为外部相机看机器人；我们是**眼在手上**，看到的是自己的一部分 + 世界，并直接用于抓取决策 |
| 交互式感知、物体中心学习 | 推动分割、Slot Attention 类 | 我们用**自身动作**作为分离信号，不碰物体 |
| 低成本机器人学习 | ALOHA、LeRobot / SO-100 | 他们有编码器；我们去掉编码器，证明仍然可学 |

**卖点一句话**：把具身智能从"有传感器的机器人"推广到"连关节传感器都没有的机器人"，低成本恰恰是问题的定义，而不是妥协。

## 6. 需要的资源
- **GPU**：训练世界模型需要一张 ≥ 12GB 显存的显卡（实验室服务器或云 GPU）；推理在 K230 + 树莓派
- **采图**：K230 存图到 SD 卡 + 时间戳；**加一根同步线**（树莓派 GPIO14 TX → K230 某 UART RX），树莓派发动作同步标记（原 10 字节帧不变）
- **真值**：舵机电位器引线到 ADC；手机支架 + 坐标纸
- 5~8 种物块、备用爪子；可选第二台低成本臂做泛化
- 导师把关选题和期刊

**风险与退路**
- 槽位分解在真实画面上不稳定 → 退到"检测框 + 动作条件动力学"的轻量版本（仍然是深度学习 + 具身）
- 世界模型规划不如脚本专家 → 论文重心放在 H1/H2（视觉本体感知 + 自身识别），规划作为下游应用
- 文献发现已有类似工作 → 强调"无本体感知 + 迟滞 + 眼在手上自身可见"三者同时成立的设定
