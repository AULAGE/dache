## 1. 要解决的实际问题

低成本移动机械臂（整车 BOM 远低于工业臂方案）普遍有三个"缺陷"，现有方法要么忽略、要么靠贵硬件解决：

| 缺陷 | 本车的真实表现（2026-11-03 实测） | 贵方案怎么解决 | 低成本下的困难 |
|---|---|---|---|
| **无关节反馈**：PWM 舵机，有死区、回差 | 底座命令 +4.8°，方位误差只从 5.0° 变到 3.4°；对准多走 2~3 步 | 编码器 / 总线舵机回读 | 不知道"实际转了多少" |
| **眼在手上的自身干扰**：爪子永远在画面里 | 跟踪器锁住爪子脚，底座转 69°、升降降 10cm | 相机装在爪子看不到的位置 / 精确掩膜 | 换爪子、换姿态都要重新人工处理 |
| **自遮挡造成的定位偏差** + **无手眼标定** | 落点系统性偏右约 4mm（对准误差已在容差内） | 精确手眼标定、深度相机 | 偏差来源混在一起，分不开 |

这三个问题在低成本平台上**普遍存在**（教学、物流、农业、助老场景大量使用舵机臂 + 单目相机），但很少被当作一个整体来研究。

## 2. 核心思想（创新点所在）

> **机器人自己的每一个动作，都是一次"免费的测量"。**

发出动作 u 之后，画面里每个检测目标的位移，在三种假设下的规律完全不同：

| 假设 | 画面位移规律 | 能推断出什么 |
|---|---|---|
| **真目标** | 位移 ≈ J · g(u; θ)（雅可比 × 执行器实际动作） | 执行器实际动了多少 → **回差、死区（视觉本体感知）** |
| **自身部件**（爪子） | 位移 ≈ 0（和相机固连） | 自动得到"自身"样本和自身掩膜 |
| **干扰物** | 不符合上面两种 | 拒绝 |

再加上**抓取成败**本身是一个信号（抓到 = 落点误差小于爪子余量），就能在线推断落点残差。

**统一框架**：一个"动作-响应概率模型"同时做三件事 —— 数据关联（谁是目标）、执行器辨识（回差/死区/增益）、残差标定（落点偏差）。
这比"三个零散技巧"强：**一个原理、一套推断，解决三个问题**，而且全部来自机器人自己的动作，不需要额外传感器、不需要人工标注。

## 3. 方法

### 3.1 动作-响应模型
- 目标在相机系的观测 z = (方位角 φ, 竖直 y, 深度 d)
- 执行器实际动作：带回差和死区的迟滞模型（play operator）
  `a_k = g(u_k; b, δ)`：反向时先吃掉回差 b，|u| < δ 时不动
- 目标：`z_{k+1} = z_k + J(z_k) · a_k + ε`，ε ~ N(0, Σ)
- 自身：`z_{k+1} = z_k + ε_s`；干扰：宽分布

### 3.2 贝叶斯数据关联（替代现在的 ghost 规则）
- 每条检测轨迹 i 维护 P(h_i = 目标 / 自身 / 干扰 | 历史位移)，用上面三种似然递推更新（交互多模型思路）
- 在线用途：伺服只跟 P(目标) 最高且超过阈值的轨迹 → **不会再锁住爪子**
- 离线用途：**自监督数据引擎**，自动给图像打标签（目标框 / 自身框 / 背景），喂给检测模型重训
- 对比现有 ghost 规则：规则要 2 步才发现、且只能止损；概率模型 1 步就能拒绝，并能"换回"正确目标

### 3.3 视觉本体感知：执行器在线辨识与补偿
- 把被确认的真目标当作"视觉编码器"：观测位移反推实际动作 a_k
- 用递推最小二乘 / EM 联合估计 (J, b, δ)；对每个关节（底座、升降）各自估计
- 补偿：前馈逆迟滞（反向时预加 b，小于 δ 的步子放大到 δ），或"同向逼近"策略
- **意义**：没有编码器的舵机，获得了近似闭环的精度

### 3.4 遮挡感知的中心估计
- 数据引擎统计出**自身掩膜** M（爪子在画面里的固定区域）
- 当目标框与 M 重叠时，可见框中心有偏差。真值自监督获得：同一物块从多个底座角度观察，
  不被遮挡的视角 + 3.1 的运动模型能推出遮挡视角下的真实中心
- 检测模型加一个轻量回归头：输入框 + 与 M 的重叠特征，输出中心修正量 Δc
- 部署在 K230 NPU（量化 int8），对比修正前后的定位误差

### 3.5 结果监督的残差标定（抓取成败当奖励）
- 落点残差 r（对每个深度段）。抓取成功概率模型：`P(成功 | 实际偏差 e) = Φ((w/2 − |e − r|) / σ)`，w = 爪子横向余量
- 每次抓取给一个有意的小探测偏移 p（安全探索：只在置信区间内），成败作为伯努利观测，贝叶斯更新 r 的后验
- 选择探测量：最大化信息增益（主动学习）；可证明在模型成立时 r 的估计收敛（随机逼近 / Robbins-Monro）
- **意义**：不做精确手眼标定，几十次抓取内自动收敛到真实偏差

### 3.6 系统（次要贡献，写在系统章节）
- 阿克曼底盘 + 升降轴 + 机械臂的冗余分配和几何前馈（已实现 `base_after_move`）
- K230 NPU（检测）+ 树莓派（推断与控制）的边缘分工；整车 BOM 成本表

## 4. 研究假设和实验

| 假设 | 实验 | 指标 | 基线 |
|---|---|---|---|
| **H1** 动作-响应关联能消除自身误锁 | 爪子在画面里，物块 + 干扰物（另一个方块、手）随机摆放 | 误锁率、关联准确率、首次正确锁定的步数 | 原始跟踪器；ghost 规则；手工忽略区域；DIJE 类稠密雅可比自识别 |
| **H2** 自监督数据引擎训练的检测器 ≥ 人工标注 | 同样图量：自动标注 vs 人工标注；再比"人工 1/10 + 自动" | mAP、自身误检率、**标注工时** | 人工标注 YOLO；预训练模型直接用 |
| **H3** 视觉本体感知补偿回差/死区 | 底座/升降命令阶跃序列，正反向 | 实际角度误差（真值：外部手机俯拍 + 角度标记，或臂上贴 IMU）、对准步数 | 不补偿；固定经验补偿 |
| **H4** 遮挡中心修正 + 结果监督标定提升抓取 | 9 位置 × 多物体 | 真实成功率、落点偏差（俯拍坐标纸测量）、收敛所需抓取次数 | 固定微调（现在的 trim）；精确手眼标定 |
| **整体** | 完整系统 vs 各种去掉一项（消融） | 成功率、用时、误报率 | — |
| **泛化** | ≥ 5~8 种物体（颜色/大小/形状）、3 种光照、**换一个爪子**、最好再一台不同的臂 | 同上 | — |

统计：每种条件 ≥ 30 次真机试验；成功率报 Wilson 置信区间；配对比较用 McNemar 检验；连续量用 Wilcoxon。
真值测量要和被测系统独立（外部相机、坐标纸、IMU），这是审稿人最容易质疑的地方。

## 5. 和已有工作的区别（初步，需要系统文献调研确认）

| 方向 | 代表工作（初步检索） | 我们的区别 |
|---|---|---|
| 稠密雅可比机器人自识别 | DIJE（arXiv 2507.00446，2025） | 我们针对**稀疏检测框 + 无反馈执行器**，统一辨识回差死区，并做数据引擎和抓取标定；面向边缘 NPU |
| 交互式感知 / 推动分割 | Self-Supervised Unseen Object Instance Segmentation via Long-Term Robot Interaction（2023） | 他们推动物体、用光流；我们**不碰物体**，只动相机，利用自身动作的可预测性 |
| 运动一致性检测 | Towards Object Detection from Motion | 他们需要物体运动的视频；我们用机器人自身动作做条件 |
| 无标定视觉伺服 / 在线雅可比 | Broyden、Kalman、最小二乘等经典方法 | 我们把雅可比估计和**迟滞辨识、数据关联**放进同一个模型 |
| 自监督抓取学习 | 大规模抓取试错类工作 | 我们只学**低维残差**，几十次收敛，可在单台低成本车上完成 |

风险：如果文献调研发现"动作条件的自身识别 + 执行器辨识"已有完整工作，就把重心移到"无反馈执行器的视觉本体感知 + 结果监督标定"，仍然成立。
