# 任务 09：抓取精度——底座消回差、失败左右试探、从结果学习落点偏差、三点插值

## 背景（2026-11-03 真机，低平台，无底盘，15 次抓到 11 次）
相关代码：`raspberrypi/grasp/task.py`（`align`、`grasp`、`run_once`）、`sim.py`、`config.py`。先读 `docs/抓取与调试方案.md`。

真机现象：
1. **落点系统性偏右约 4mm**：对准结束时误差已在容差内（|x| < 1.5°）。现在用固定微调 `GRASP_BASE_TRIM_DEG` 补（用户会设 −1.3°）。
   偏差可能随位置变化（物块越靠画面左侧，越容易被爪子脚遮挡左边 → K230 框中心偏右）
2. **底座小角度修正不到位**：例如命令 +4.8°，方位角误差只从 5.0° 变到 3.4°；对准常要多走 2~3 步。
   底座是 LDX-218 数字舵机，200us ≈ 18°，有死区和回差
3. 无底盘时深度不对准，伸出姿态在 reach_near（156mm）和 reach_far（216mm）之间**关节空间线性插值**，中间深度时爪子高度可能偏

## 目标（每一项都要有 `config.py` 开关，默认关 = 现在的行为；加进 `CALIB_KEYS`）
1. **底座消回差** `BASE_BACKLASH_DEG`（默认 0 = 关）：底座反向转动时先多转这么多再回来，保证最后总是从同一方向逼近；
   `BASE_MIN_STEP_DEG`：误差超过容差但算出来的步子小于这个值时，按这个值走（越过死区）
2. **失败后左右试探** `GRASP_PROBE_MM`（默认 0 = 关）：没抓到重试时，在当前微调基础上交替加 −p、+p（换算成底座角度），
   不要原样再抓一次
3. **从结果学习落点偏差** `TRIM_LEARN`（默认关）：按深度分 3 段（近/中/远，可配置），每段一个微调值，存 `logs/learned_trim.json`。
   - 试探成功 → 该段微调往成功的方向挪 `TRIM_LEARN_RATE × p`
   - 不试探直接成功 → 不变；连续失败 → 不乱改（记录即可）
   - 微调幅度限制在 ±`TRIM_MAX_DEG`
   - 这是"用结果（奖励）学参数"，不需要神经网络，但要在报告里说明它会不会学偏、怎么防止
4. **三点插值**：支持可选的 `reach_mid` 姿态 + `REACH_MID_D` + `GOAL_MID`（没标就按两点插值，行为不变）；
   `calib.py teach mid` 能标它

## 仿真
`sim.py` 现在的机械爪模型（`SimArm.GRIP_TOL`）没有"落点偏差"和"底座回差"。要加上：
- 每台车固定的落点横向偏差（例如 +3~5mm，偏右），可以随物块在画面里的位置变化（模拟遮挡）
- 底座舵机死区 + 回差（任务 02 已有 `SIM_SERVO_*` 相关开关，复用）
- 横向容差：物块 24mm，爪子张开约多大（估计值，写明）

然后比较：现状 / +消回差 / +试探 / +学习 / 全开，各 10 台车 × 100 次：真实抓到率、平均重试次数、步数、用时、学到的微调是否收敛到真实偏差。
