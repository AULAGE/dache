## 1. 代码路径审查（真机参数下）

真机参数取自 `CLAUDE.md`：`R_CAM_MM = 0`、`BASE_DIR = −1`、近 156mm→Y+70、远 216mm→Y+43、`VERIFY = "observe"`、
`ACK_MIN_RADIUS_MM = 600`（估计）、滑行 τ ≈ 0.45s（"100mm 走 145mm"是没有滑行模型时的结果）。

### 1.1 `devices.WheeltecChassis`

| 项 | 行为 | 结论 |
|---|---|---|
| 50Hz 发送 + `CHASSIS_CMD_TTL_S = 0.5` | 主线程 0.5 秒不刷新指令 → 发送线程改发 0 | ✅ 有效（假串口测过；真机用 `--hang` A 项确认） |
| `close()` / `atexit` | 直接写 3 帧停车帧 | ✅；但 **SIGTERM / SIGHUP 不触发 atexit** → 问题 6 |
| `drive()` 开始时 `fb = has_feedback()` 只取一次 | 有回传 → 按里程走；**中途回传断了**，`done` 不再增加，按 `remaining × RAMP_K` 一直以最高速开到超时（`target/30×1.5+3` 秒，400mm = 23 秒） | ❌ → 问题 5，循环里每拍检查 `has_feedback()` |
| 开始时就没回传 | 按时间开环走 `target/speed` 秒 | 可接受：`main.py` 启动前检查要求底盘有回传（除非 `--force`） |
| 阿克曼转角截断 `max_dpsi = mm / min_radius` | `ACK_MIN_RADIUS_MM` 配小了也只是请求做不到的弯，固件自己截；实际转角由回传积分 | ✅ 仿真：真实半径 900、配置 600，成功率 86%（配置正确 85%），0 危险 |
| 超时 `DeviceError` | `main.py` 连续模式下 3 秒后重开设备再来 | ⚠ 车被平台卡住时会反复顶（没改，手册要求先 `--once`） |

### 1.2 `task.align` 底盘分支

| 分支 | 审查 | 结论 |
|---|---|---|
| 深度轴 `u_d = AXES["d"]` 一步最多 **400mm** | 读数正确时没问题；读数错时一步就是 40cm | 本身不改（真机对准需要），配合问题 1~3 的保护 |
| ghost 检查 | 原来只查 y（升降）和 x（底座，且**开车时不查**）。爪子脚读数恒定 + 有深度误差 → 每步都开车 | ❌ → 问题 1，按实际里程预测深度变化（乘 cos(底座角)，预测 < 30mm 不查） |
| 边走边转 `drive(u_d, base_new)` + 几何前馈 `base_after_move` | 前进 / 后退的转向符号、按弧中点近似都核对过；`R_CAM = 0` 时几何简单 | ✅ 仿真里"转向打满"最长连续 2 次、车头累计 ≤ 34°，没有兜圈 |
| 走完后直接信新读数 | 读数跳变（误识别 / 跟踪器换目标）时照着开 | ❌ → 问题 3 |
| `BASE_LIMIT_BACKUP_MM`（默认 0） | 只在底座转到 ±85° 还差时触发；物块在 ±30° 内**一次都没触发**（打开和不打开结果逐项相同） | 不危险；手册里不建议这次打开 |
| 阿克曼 `recenter` 只在有 `u_d` 时才拐 | 深度已对好、底座偏大时不会去拐（避免原地兜） | ✅ |

### 1.3 搜索、重试

| 项 | 审查 | 结论 |
|---|---|---|
| 搜索先 `SEARCH_LOOK_FIRST` 原地看一眼（会复核），再扫底座角（`SEARCH_CONFIRM = False` 时**不复核**） | 有底盘时一次误识别就开 400mm | ❌ → 问题 2 |
| 搜索后退 `SEARCH_BACKOFF_MM = 250` | 每次搜索最多退一次；`run_once` 里最多搜 4 次；`main.py` 连续运行时**跨次数累加没有上限** | ❌ → 问题 4 |
| 抓取失败 `release_and_back_off` 后退 60mm | 每个物块最多 3 次 = 180mm | ✅ |
| 视场 | K230 `ROTATE_DEG = 90`、1280×720、`FOCAL_PIX = 944` → 水平半视场 21°、竖直 34°；`config.py` 的 `FOV_X/Y = 35/25` 是没转之前的值（只有仿真用） | 默认搜索角 `[0, ±55, ±85]` 在 21°~34° 有空档 → 手册建议加密（已把 `SEARCH_BASE_DEG` 加进 `CALIB_KEYS`） |

### 1.4 进程退出

`setup/grasp.service` 里写着调试时 `sudo systemctl stop grasp`，`main.py` 没有信号处理 → SIGTERM 直接杀进程，`finally` 和 `atexit` 都不执行，
固件保持最后一帧速度（任务 03：没有超时）。SSH 窗口关掉（SIGHUP）同理。→ 问题 6。`kill -9`、断电、USB 掉线仍然拦不住，手册第 0 节写明只能拨开关。

## 4. `chassis_test.py`

| 命令 | 做什么 | 写什么 |
|---|---|---|
| `--voltage` | 只读：电压、flag、vx/wz、陀螺仪原始值（3 秒） | — |
| `--hang` | 架空：A 指令过期自动停、B `close()` 停、C 子进程收 SIGTERM 停；任何一项 ❌ 提示不能下地 | — |
| `--timeout-check` | 不经过驱动，验证固件有没有串口超时（原有） | — |
| `--ruler [--fresh] [--write]` | 默认 `--dist 100,200`：+100×3、−100×3、+200×3、−200×3；按距离分组汇总里程误差 / 尺子误差、航向漂移；拟合"尺子 / 里程"比例和滑行 τ | `calib.json` 的 `CHASSIS_PI_TAU_S` + `logs/chassis_tau.json`（main.py 实际读的 τ 文件，否则旧的学习值会覆盖 calib） |
| `--radius [--write]` | 驱动截断临时放到 150mm，让固件自己打满；左、右各走 600mm 弧；输入弦长和侧移 → R = 弦长²/(2·侧移)；取大的一边 +5% | `calib.json` 的 `ACK_MIN_RADIUS_MM`（只有两边都用尺子量了才写；陀螺仪推算的不写） |

- 里程计比例偏 > 3% 或 τ 离散 > 0.1s 时，`--write` 写驱动按里程学到的 τ，不写尺子拟合值（尺子拟合不可信）
- 写 calib 只改这一项、保留原有标定，键必须在 `CALIB_KEYS` 里（测试覆盖）
- 云端验证：纯计算函数有单元测试；`--ruler --write`、`--radius --write`、`--voltage` 用 selftest 的**固件假控制器**干跑通过（输出格式正常、写 calib 正常）；
  `--hang` 和 `--timeout-check` 要真串口，**没跑过**

## 5. 手册 `docs/底盘联调手册.md`

0 安全（哪些情况能自动停、哪些只能拨开关）→ 时间安排 → 第 0~8 步（准备、只读、架空、直走、半径、量车头摆场地、单步、全自动、bench 对比）
→ 11/9 决策标准 → 贴什么给云端 → 记录表。每一步都有命令、预期现象、通过标准、"现象 / 判断 / 处理"表。

特别提醒的一条（仿真里看不出来）：有底盘时程序会把**底座转轴开到离物块约 156mm**（`R_CAM = 0`、`GOAL d = 156`）。
车头比底座转轴还往前伸 F，平台挡在物块前面 E 时，要求 F + 30 ≤ 156 − E，否则一定撞平台。手册第 5 步让用户先量。

决策标准（摘要）：**全部**满足才用底盘——架空三项 ✅、联调全过程 0 次危险动作、bench 有底盘 ≥ 70% 且不比无底盘低 10 个百分点以上、平均 ≤ 60 秒、
比赛确实需要底盘、车头不撞平台；拿不准就不用。

## 7. 没在真机验证的（全部）

- 6 个修复都只在仿真 / 假串口上验证；SIGTERM 测试用的是假串口的子进程
- `chassis_test.py --hang`、`--timeout-check` 没跑过；`--ruler`、`--radius`、`--voltage` 只在固件假控制器上跑过
- 统计用的"真机标定近似"是按 `CLAUDE.md` 里的数字拼的，真机 `calib.json` 不在仓库里；仿真相机是水平的，Y+70 当成"物块在下方"处理，真机相机可能是俯视的
- K230 水平半视场 21° 是按 `ROTATE_DEG = 90` 和 `FOCAL_PIX` 算的，没有实测；加密搜索角的收益依赖它
- 危险判定线（600mm、90°、60mm、3m）是我定的估计值

| 电池电压只在启动时检查 | 跑的过程中掉到 22V 以下不会停 | 真机跑一段时间看掉压速度再决定 |
| 深度轴一步最多 400mm | 真机对准要用；有了问题 1~3 的保护 | 第一次上车如果不放心，可以在 `config.py` 临时改小（`AXES["d"]["max"]` 不在 calib 白名单里） |
| `kill -9` / 断电 / USB 掉线 | 树莓派端无能为力 | 只能靠使能开关；手册第 0 节 |
