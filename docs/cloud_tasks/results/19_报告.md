## 3. 怎么填 data.json

用记事本 / VS Code 打开 `build\data.json`，每一节开头的 `_说明` 写了怎么填。JSON 注意：英文双引号、最后一项后面没有逗号、Windows 路径写成 `D:/大车/x.jpg`。

| 节 | 填什么 | 文档里哪里用 |
|---|---|---|
| `队员` / `分工` | 名单、分工比例（从旧概要表照搬），核对后 `已核对` 改 `true` | PPT 封面、致谢页、概要表 |
| `核对事实` | 草稿里的【请核对】事实（丝杠导程、上一版相机位置、扩展功能是否展示、电池），核对后 `已核对: true` | 报告 1、3.2、3.7、4.1、4.5 节；PPT 版本迭代页 |
| `开关` | `比赛版启用失败试探与学习`、`底盘参与抓取已联调`：`true` / `false`，`null` = 未定（保留段落并标【请核对】） | 报告 3.5、5.3、6.3；PPT 抓取确认页、视频⑧页、展望页 |
| `真机` | 测试环境、平台高度、有底盘结果、结果分析、底盘联调结论 | 报告 5.1、5.3、5.6 |
| `bench` | **推荐**：把树莓派 `raspberrypi/grasp/logs/bench.csv` 拷到 `build\media\`，`csv文件` 写 `"bench.csv"`（`轮次` 空 = 最新一轮，`"all"` = 全部；默认只算无底盘）。也可以手填 9 个格子 | 报告表“真机测试矩阵结果”；PPT 测试结果页（成功率、平均用时、讲稿里的数字） |
| `改进对比` | 基线 / +trim / +试探学习 各测了几次、抓到几次（没测的行删掉） | 报告 5.3 |
| `各阶段用时_s` | 搜索、对准、伸出夹取、确认、放置的平均秒数 + 来源 | 报告 5.3 |
| `仿真` | 已填（2026-11-03，提交 d7f6aca，默认配置）。重跑后可以替换 | 报告 5.2；PPT 开发方法页（都标“仿真”） |
| `视频` | 按拍摄清单 ①③④⑤⑦⑧ 写 `media\` 里的文件名 | PPT 第 14~17 页 |
| `照片` | 整机、K230画面、抓取序列（6 张）、终端日志、bench报告、看板、封面背景 | 报告图 1、4、8、9、10；PPT 第 1、4、20 页 |
| `概要表` | 简介、创新（自动检查 ≤100 字，超了会标黄）、特别说明、平台、工具、参考文献 | 概要表 |

每次运行后看 `out\缺项清单.txt`：列出还缺什么、在哪一页/哪一节。

## 4. 照片和视频

- 全部放进 `build\media\`，文件名随意，写进 data.json。大照片会自动缩到 1800 像素转 JPEG（原图不动）。
- 视频：mp4（H.264）。PPT 里直接嵌入（文件会变大，U 盘里注意空间）；封面帧用 ffmpeg 截第 1 秒，没有 ffmpeg 就用深色封面。
  没填的视频位显示“待补视频 + 拍摄清单编号 + 怎么拍”。
- `看板` 默认用任务 16 的**仿真**截图（图注写明了“仿真运行时的截图”）；换成真机截图后，把草稿里那张图的图注改掉。
- PPT 第 4 页没有新整机照片时，用旧版三维模型顶着，并标黄【待图：换成新整机照片】。

## 5. 生成后在 Office 里还要手动做的

1. **Word 目录**：打开报告时如果提示“是否更新域”，选“是”；否则右键目录 → 更新域 → 更新整个目录。图/表编号也会一起更新。
   目录第一行的黄色提示会在更新后消失。
2. **全文搜黄色高亮**（开始 → 查找 → 高级查找 → 格式 → 突出显示），确认都处理了；`缺项清单.txt` 为 0 项最好。
3. 报告里两处图注需要看一眼：图 3（旧版三维模型，图注已写明“相机已改装到腕部”）、图 7（看板仿真截图）。
4. **PPT**：放映检查每个视频能播放；讲稿在“备注”栏（视图 → 备注页）。测试结果页的讲稿会带上 bench 的总数和成功率，但“哪些位置好/差、失败原因”要自己补。
5. **导出 PDF**：Word / PowerPoint：文件 → 另存为 → PDF。（`--pdf` 用 LibreOffice 转的版本不会刷新目录页码，只适合预览。）
6. 概要表：核对“相关文件”9 行的版权状态（`k230_sdcard`、`底盘代码` 两行标了【请核对】），按比赛要求导出 PDF。

## 6. 设计说明

- **报告**：打开旧版 docx，保留封面和目录所在的第一节，删掉正文，用旧文档里各级标题、正文段落、图注、图表段落、表格的段落格式（深拷贝）重新排正文；
  表格沿用旧版三线表的 `tblPr`；目录保留 `TOC \o "1-3"` 域，预先写好章节标题（无页码）并设 `updateFields`，Word 打开即可刷新；不再引用的旧图片从包里删掉。
- **PPT**：打开旧版 pptx，记下封面背景图后删掉全部旧页（旧视频和图片不会留在文件里），用旧版式重新画 20 页。黄色占位用 PowerPoint 的文字突出显示（`a:highlight`），**PowerPoint 2019 / Microsoft 365 才显示黄底**，更老的版本只显示文字。
- **概要表**：在旧表格上原位替换文字（保留每格第一段的字体格式），“相关文件”不够的行复制最后一行补上。
- **草稿格式**：`{{路径}}` 取值、`{{核对:名字}}`、`![图注](photo:键)`、`表{键}：标题`、`[[表:bench]]`、`[[如果:开关]]…[[否则]]…[[结束]]`、`$$ 公式`，写法在草稿开头。以 `>` 开头的行不进报告。
