## 3. 每一项的原理

### 3.1 底座消回差 `BASE_BACKLASH_DEG`、`BASE_APPROACH_DIR`

- 做法：程序记住最后一次发给底座的脉宽和转动方向。新的底座目标如果要**反着** `BASE_APPROACH_DIR` 转（或者状态未知），
  先多转 `BASE_BACKLASH_DEG` 度，再顺着逼近方向转回来。这样最后一段总是从同一边过来，齿轮总是靠在同一侧。
- 哪些动作做：对准时转底座、回观察姿态、伸出（ready / reach / carry）、观察确认。放置（drop，转到 2287）不做。
- 只动底座时，回程只走 `BASE_BACKLASH_DEG` 那么远，用时按这个算（最少 150ms）；带其它关节的姿态（ready）两段都用原来的时间。
- 代价：仿真里每次抓取多 2~4 秒（每多转一次约 0.3 秒，对准、回观察、伸出都可能要多转）。
- **为什么单独开会变差**：它不减少偏差，只让偏差**固定下来**。仿真里合爪时"物块相对对准目标"的横向偏差：
  关闭时四分位 −3.7~+0.1mm（散），打开后 −4.4~−0.9mm（集中，但中心还偏）。散的时候偶尔碰巧能补上 4mm 的落点偏差，
  集中之后就稳定地抓不到。再加上"伸出时推底座"：逼近方向和被推的方向相同时，每次都多偏一个回差（1.8° ≈ 5.7mm）。
  → **消回差的价值是让偏差变成能补的固定值**：不开回差时学习只能把误差从 1.51° 学到 1.08°（不推底座的环境），开了能学到 0.53°。
- `BASE_APPROACH_DIR` 选哪边：仿真里两边各有一半车更好，看伸出时底座被推向哪边。真机上开了之后先试 1，不好再试 −1（每次换了都要 `trim forget`）。

### 3.2 底座最小有效步长 `BASE_MIN_STEP_DEG`

- 方位角误差超过容差、但算出的步子比这个小时，按这个值走。最多放大到"预测误差 = 反方向 0.9 倍容差"，不会冲到另一边来回摆。
- 仿真里没效果（1° 从不触发：R=0、灵敏度 −1 时，误差 >1.5° 算出来的步子都 ≥1.27°；把死区加到 15us、步长 2~3° 也没改善）。
- 真机灵敏度约 −0.6，误差 1.6° 时步子是 2.3°，所以要设 **2.5°** 左右才可能起作用。这一项仿真验证不了，排最后。

### 3.3 失败后左右试探 `GRASP_PROBE_MM`

- 第 1 次伸出不试探；没抓到，重新对准后第 2 次落点偏 −p（左），第 3 次偏 +p（右），再往后 −2p、+2p……
- 毫米换成底座角度：`atan(p / (深度 + R_CAM_MM))`。真机 R=0，按深度算。
  ⚠ 如果真机相机其实在转轴后面（灵敏度 −0.6 暗示可能是这样），爪子到转轴的距离比深度短，实际挪的毫米数会比 p 大一些。
- `GRASP_PROBE_FIRST = "alternate"`：每个物块换一边先试（学习时必须这样，见 3.5）。
- 仿真：单开试探 69.6% → 80.0%，p 扫了 2/3/4/6mm，**3mm 最好**（p 太大容易试过头、推开物块）。

### 3.4 从结果学习落点偏差 `TRIM_LEARN`

- 按物块深度分 3 段（默认把 `[REACH_NEAR_D, REACH_FAR_D]` 三等分；真机 156/216 → 边界 176、196mm），每段一个微调值，
  加在固定微调 `GRASP_BASE_TRIM_DEG` 上。
- 规则（一个物块结束时）：
  - 第 1 次就抓到 → 不改（现在的微调够用）
  - 试探 ±p 抓到了 → 这一段往那边挪 `TRIM_LEARN_RATE × p`（换成角度）
  - 都没抓到 → 不改，只计数
  - 限制在 ±`TRIM_MAX_DEG`（默认 3°）
- 存 `logs/learned_trim.json`（每段的值和"直接抓到 / 左试探抓到 / 右试探抓到 / 都没抓到"次数），`calib.py trim` 能看，
  `calib.py trim forget` 清掉。深度分段变了（重新标了近/远）会自动作废重学。`--no-learn` 时只用不改。
- 这就是"用奖励学参数"：奖励 = 抓到没有，学的是落点偏差；本质是一种有限差分的随机逼近（两边各试一下，哪边好往哪边走），不需要神经网络。

### 3.5 会不会学偏？怎么防

| 风险 | 后果 | 防护 |
|---|---|---|
| 第 1 次没抓到是随机原因（打滑、物块被碰歪），不是偏差 | 试探往哪边都可能成功，会往试探方向挪一步 | `alternate`：先试的方向每个物块轮换，随机失败带来的挪动期望为 0；如果固定先试左，随机失败会让微调一直往左漂 |
| 稳态抖动 | 步长固定（0.5 × 3mm ≈ 0.5°），不会收敛到一个点，会在真值附近 ±0.5° 晃 | 仿真里 40~60 次后误差约 0.5°，跑到 200 次也没漂走（见 4.3）；±`TRIM_MAX_DEG` 兜底 |
| **观察确认误报**（物块被推开 10~30mm 当成抓到） | 推开往往是试探方向偏了造成的 → 会把错的方向学进去 | 现有的弱点（仿真 1000 次里 2~8 次误报）。看 `bench.py report` 的误报数；`calib.py trim` 里某一段只往一个方向涨、成功率却不涨时就 `trim forget` |
| 偏差和深度、左右位置都有关 | 只按深度分段，左右位置的差别学不到，会学成平均值 | 测试矩阵里如果"只有左边/右边偏"，说明是左右相关，学习补不了，先看任务 10（爪子脚遮挡） |
| 改了机械（消回差开关、逼近方向、重新装爪子、重标姿态） | 旧的学习结果不再适用 | 换了就 `calib.py trim forget`；重标近/远会自动作废 |
| 数据少的段 | 学得慢（只有失败 + 试探成功才学） | 测试矩阵每段都有位置；学到的值和次数用 `calib.py trim` 看 |

### 3.6 三点插值 `reach_mid` / `REACH_MID_D` / `GOAL_MID`

- `calib.py teach mid`：和 teach near/far 一样的倒推法（物块放进爪子 → 合爪确认 → 松爪退回观察姿态读数）。
  没标过时用 reach_near 和 reach_far 的中点当初值，按 `j` 点动调整。保存 `POSES.reach_mid`、`REACH_MID_D`、`GOAL_MID`。
  `calib.py teach mid off` 删掉，恢复两点插值。
- 伸出姿态和无底盘时的对准目标（Y、方位角）都按 近-中、中-远 分段插值。`REACH_MID_D` 不在近、远之间时不用它。
- 仿真（两点插值时中间深度爪子高度偏 sag，抛物线模型）：

| 中间深度高度偏差 | 两点插值 | 标了 reach_mid |
|---|---|---|
| 0mm | 87.0% | — |
| 6mm | 77.4% | 79.8% |
| 10mm | 54.5% | 79.6% |

  （都是"全开"。标了 reach_mid 还剩的损失来自分段之间的残余偏差。）真机中间深度到底偏多少不知道，所以**先看测试矩阵**：
  ④⑤⑥ 失败、①②③⑦⑧⑨ 成功才标。

| 全开（消回差 2° + 最小步长 1° + 试探 3mm + 学习） | 86.8% | 93.0% |

差别在统计误差内（±1.3%）。默认环境里没有落点偏差，所以全开不会带来好处，只多花约 1~3 秒。

## 5. 明天真机：打开顺序和参数初值

改参数：编辑树莓派上 `~/grasp/calib.json`，加对应的键（都在白名单里），保存后重新运行即可。
每一步都用 `bench.py` 跑一轮测试矩阵（18 次），**用 bench 的"真的抓到没有"判断好坏，不看程序自己说的**。

**第 0 步：基准**（不改代码行为）
```bash
cd ~/grasp

```

**第 1 步：试探 + 学习（保留 trim 4）** ← 仿真里 6 种环境 4 种更好、2 种持平
```json

"GRASP_PROBE_FIRST": "alternate",
"TRIM_LEARN": true,
"TRIM_LEARN_RATE": 0.5,
```

- 跑 2~3 轮（36~54 次）。每轮后 `python3 calib.py trim` 看三段学到了什么、`python3 bench.py report` 看真实成功率和误报
- 正常：三段的值在 ±1.5° 以内，左右试探成功次数有来有回
- 不正常：某一段一直往一个方向涨到 ±3° → 多半是误报（被推开当成抓到）或者偏差和左右位置有关 → `calib.py trim forget`，把日志发给我
- 日志里会看到：`抓取：…（微调 −1.8° = 固定 −1.3° + 学到 −0.50° + 试探 +0mm）`、`学习落点：深度 …mm 那一段，试探 −3mm 抓到了 → …`

## 6. 没做 / 局限

- 仿真里的偏差、容差、回差、"伸出时推底座"全是估计；尤其"伸出时推底座"决定了消回差的好坏，必须真机测。
- 学习只按深度分段，左右位置相关的偏差（爪子脚遮挡）学不到，要靠任务 10 从根上解决。
- 观察确认的误报（物块被推开当成抓到）会污染学习；这个问题本身不在本任务范围。
- 试探量按"转轴到物块 = 深度 + R_CAM_MM"换算角度；真机 R 标成 0，如果相机其实在转轴后面，实际挪的毫米数会偏大。
- 消回差每次抓取在仿真里多 2~4 秒。
