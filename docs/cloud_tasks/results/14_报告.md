# 任务 14 报告：世界模型原型——合成腕部相机图像上验证"学出本体感知"（H1）和"自身/世界分离"（H2）

> **全部结论来自合成数据，没有用任何真机图像。** 而且是 4 核 CPU 上每个变体只训练 15 分钟（约 1100 步）的结果，
> 对 Slot Attention 类模型来说**严重训练不足**（文献里一般是 GPU 上几万到几十万步）。下面的负结果只说明"这个规模下没做出来"，
> 不能说明方法本身不行。

分支：`cloud/14-world-model`。只在 `raspberrypi/grasp/research/worldmodel/` 下新建了文件（外加本报告），
没有改任何已有文件；`selftest.py` 原有 143 项全部通过（它不依赖 torch / numpy）。

## 0. 一页结论

| 问题 | 结果（合成数据，完整模式，测试集 200 条序列） | 结论 |
|---|---|---|
| H1：隐状态能否线性解码真实舵机角，比命令积分准多少 | 底座误差：命令积分 1.19° → **方向记忆规则 0.77°** → 完整模型 0.74°；但**未训练的同结构模型（随机权重）也有 0.76°** | 比命令积分好 38%，但**几乎全部来自"记住上次往哪边转"**，随机 GRU 也能做到。训练带来的增益只有 0.02°（回差 ≥3.5° 那组 1.12° → 1.06°），在这个规模下**不显著，H1 没有被证实** |
| H2：不给标注能否分出爪子 / 物块 | 爪子最佳 IoU 全部 < 0.05；物块：无分离先验 0.46，完整模型 0.06 | **没有做出来**。完整模型塌缩成一个槽位覆盖整幅画面（见第 3.2 节），反而是没有分离先验的变体能用一个槽位跟住物块 |
| 验收：`train.py --quick` CPU 10 分钟内 | 478 秒，输出全部指标 | ✅ |

**最有价值的发现**（第 3 节）：
1. **"随机初始化的 GRU"是 H1 必须有的对照**：只看"比命令积分准多少"会得出"学会了本体感知"的错误结论（38% 改进），
   但随机权重的 GRU 当储备池就能解出同样多。论文里 H1 的实验一定要报这个对照和"方向记忆规则"基线
2. **像素级的分离先验会导致整图塌缩**："世界像素按相机运动平移"在背景占大部分画面时，最省事的解是一个槽位包住全图、整体平移；
   爪子只占约 3%，判错的代价太小。分离先验必须和"槽位不能太大 / 每个槽位都要用上"的约束一起用
3. **信号本身是存在的**：用真实相机运动（含回差）平移上一帧去预测下一帧，误差比只按命令平移低 40%（0.0012 vs 0.0020）；
   训练出的模型做到 0.0016，学到了约一半。也就是说回差信息确实在画面里，问题出在表示（GRU 隐状态没有把它整理成线性可读的形式）和训练量

## 1. 做了什么

| 文件 | 内容 |
|---|---|
| `render.py` | numpy 2D 渲染器，64×64：物块（解析抗锯齿，亚像素位置）；爪子脚固定在画面左侧中间（张 / 合两种形态，画在最上层、会遮挡物块）；世界固定的背景纹理（墙 / 台面分界，随相机移动）；每帧光照增益 0.85~1.15 + 序列色调；像素噪声 σ=0.02；30% 序列有另一个物块、30% 有独立乱动的"手"；物块可以部分出画面 |
| `dataset.py` | 自主探索策略（不看画面）：底座随机游走（35% 换向，步长 0.3~4°，±12°）、升降一半的步动 0.05~0.6cm、爪子 10% 概率张合。执行器复用 `research/sim_world.py` 的 `play()`（死区 + 换向回差，和 `sim.SimArm._servo_base` 同一规则），回差 / 死区用 `sim_world.CAR_RANGES`，底座再乘 0.5~2 倍（回差 0.25~6°）。输出 (o_t, u_t, o_{t+1}, 真实角, 真实掩膜)，真值只用于评估 |
| `model.py` | CNN 编码器 → Slot Attention（K=4，初值 = 上一步预测，SAVi 式）→ 槽位 (z, 质心 p)；迟滞记忆 GRU（输入命令 + 槽位位置）；动作条件动力学 + 分离先验；空间广播解码器（逐像素 MLP + 傅里叶位置 + 局部性高斯先验）。4 个变体 |
| `train.py` / `eval.py` | 按时间预算训练、H1 线性探针、H2 IoU、槽位可视化、结果表 |
| `README.md` | 怎么跑、模型、评估、**换成真机图像（任务 12 的数据集）要改哪里** |
| `results/` | 两次运行的日志、结果表（md / json）、权重（每个约 0.2MB，共 1.7MB）、槽位分割图、数据预览图 |

### 1.1 模型（最终版本）
```
 o_t ─CNN─► 特征 ─Slot Attention─► 槽位 (z_k, p_k)
 [u_t, p_t] ─GRU─► h_{t+1}
 相机运动  Δc_t = A·Δ命令_t（物理先验，2×2 线性）+ W·h_{t+1} − W·h_t（迟滞修正，只能从 h 来）
 动力学    p̂_k = p_k + w_k·Δc_t，ẑ_k = z_k + MLP(z_k, u_t)，w_k = sigmoid(MLP(z_k))：0 自身 / 1 世界
 损失      重建 o_t + 预测 o_{t+1} + 平移预测 ô_{t+1} = Σ m_k[w_k·平移(o_t, Δc) + (1 − w_k)·o_t] + 0.1×质心位移正则
```
变体：`full`；`noprior`（每个槽位位移由 MLP 自由给出，没有 w、没有 Δc）；`nogru`（h = MLP(当前命令, 当前槽位)）；`cmdonly`（GRU 不看画面）。

### 1.2 评估
- **H1**：冻结模型，岭回归探针（只用训练序列拟合）从 h_t 预测"真实输出 − 命令"，θ̂ = 命令 + 探针输出（命令是机器人自己知道的）。
  基线：命令积分；方向记忆规则（θ̂ = 命令 − k·上一次转动方向，k 在训练集上拟合）；对照：同样初始权重的未训练模型
- **H2**：解码器槽位掩膜（argmax，32×32）和真实掩膜的 IoU：最佳匹配 IoU；不看真值自动判"哪个槽位是自身"（按 w 最小 /
  按序列内质心位移最小、排除铺满全图的槽位）后的爪子 IoU 和判别正确率

## 2. 结果（合成数据）

### 2.1 完整模式：训练 1200 条 × 24 步，测试 200 条，每个变体 15 分钟（约 1100 步），4 核 CPU，总用时 66 分钟

**H1：底座 / 升降真实输出的平均绝对误差**

| 方法 | 底座 ° | 升降 cm | 回差 0~1° | 1~2° | 2~3.5° | ≥3.5° | 回差方向识别率 |
|---|---|---|---|---|---|---|---|
| 命令积分（开环） | 1.188 | 0.0845 | 0.495 | 0.870 | 1.429 | 1.917 | — |
| 方向记忆规则 | 0.774 | **0.0376** | 0.602 | **0.457** | 0.817 | 1.400 | 91.7% |
| 对照：未训练的同结构模型 | 0.755 | 0.0528 | 0.660 | 0.595 | 0.751 | 1.116 | 93.1% |
| 完整模型 | **0.738** | 0.0531 | 0.652 | 0.598 | 0.735 | **1.058** | 93.1% |
| 无分离先验 | 0.752 | 0.0532 | 0.666 | 0.604 | 0.749 | 1.083 | 92.7% |
| 无 GRU（只用当前命令 + 画面） | 0.776 | 0.0615 | 0.616 | 0.576 | 0.772 | 1.255 | 91.3% |
| GRU 只看命令 | 0.753 | 0.0530 | 0.670 | 0.606 | 0.734 | 1.102 | 92.6% |

- 所有带记忆的方法都比命令积分好约 37%，但和"随机 GRU"的差距只有 0~0.02°；完整模型在回差最大那组（≥3.5°）最好（1.058 vs 1.116），
  方向一致但只是一次运行、一个种子，**不能当结论**
- 升降轴回差很小（0.05~0.3cm），方向记忆规则最好；神经网络探针反而差（隐状态里底座信息占主导，岭回归没把升降分出来）
- 去掉 GRU 明显变差（尤其回差大时 1.255），说明"命令历史"是必需的——但这本身就是方向记忆的作用

**H2：IoU**

| 变体 | 爪子最佳 IoU | 物块最佳 IoU | 按 w 判自身：爪子 IoU / 正确率 | 按位移判自身：爪子 IoU / 正确率 |
|---|---|---|---|---|
| 完整模型 | 0.018 | 0.057 | 0.000 / 0% | 0.000 / 0% |
| 无分离先验 | 0.041 | **0.463** | — | 0.017 / 28% |
| 无 GRU | 0.025 | 0.109 | 0.002 / 0% | 0.001 / 3% |
| GRU 只看命令 | 0.023 | 0.169 | 0.000 / 0% | 0.000 / 0% |

## 3. 失败的尝试（按时间顺序，都在完整模型上、quick 数据、6~8 分钟训练）

| # | 做法 | 现象 | 原因 / 处理 |
|---|---|---|---|
| 1 | 卷积空间广播解码器 | CPU 上每步 1~2 秒，10 分钟只能训几十步 | 换成逐像素 MLP 解码器（第一层拆成 z 部分 + 位置部分），便宜约 4 倍 |
| 2 | MLP 解码器，没有局部性 | 槽位是条纹状噪声，IoU < 0.1 | 解码器 alpha 加 −|像素 − p|²/2σ²（σ 由 z 决定）；同时降低背景纹理对比度、把物块放近（变大）。之后物块 IoU 到 0.50 |
| 3 | 只靠"槽位质心位移 = w·Δc"学相机运动 | 所有 w 塌到 0，c 不学 | 随机初始化的 Δc 让预测变差 → 模型关掉 w → c 没有梯度（局部最优）。改成 c 零初始化、w 初始偏"世界" |
| 4 | 加像素级平移预测损失 | 平移损失不降 | 每帧光照增益 ±15% 是损失里最大的项。加每帧按通道均值归一化（无监督） |
| 5 | Δc 全部由 GRU 给出 | Δc 方向对（相关 0.84）但幅度只有真实的 1/3~1/20 | 加物理先验 Δc = A·Δ命令 + 迟滞修正；A 随机初始化时学成了反方向 → w 又全关掉；A 也零初始化 |
| 6 | 质心位移正则权重 1.0 | A 只学到最优值的 1/5 | 槽位还没跟上物体时，质心几乎不动，这个正则把 Δc 往 0 拉。权重降到 0.1 后 Δc 幅度正确，平移损失降到 0.0016~0.0018（只按命令 0.0020，真实运动 0.0012） |
| 7 | 完整训练（最终版本） | H2 塌缩成一个全图槽位 | 见第 0 节第 2 条：平移损失鼓励"全图一起平移"。没来得及修 |

### 3.1 下一步该怎么改（按优先级，都没做）
1. **防止整图塌缩**：平移损失只对"紧凑"的槽位生效；或者加槽位面积上限 / 每个槽位使用率的熵正则；或者先只用重建损失预训练槽位，再打开平移损失
2. **H1 的读出**：让模型显式输出"估计的实际位置 − 命令"（一个标量 / 轴），探针直接读它，而不是从 64 维 GRU 状态里线性解码；
   并且把 A·Δ命令 换成"按估计的执行器状态推演"（把任务 11 的 play() 迟滞模型做成可微的一层，b、δ 作为每条序列推断的隐变量）——这就是论文方案"物理先验"的消融
3. **训练量**：同样的配置在 GPU 上训 2~5 万步，才能判断 H1/H2 能不能做出来
4. **多种子**：现在只有种子 0，差 0.02° 这种量级必须 ≥3 个种子 + 置信区间

## 4. 和论文假设的对应

| 论文方案 v2 | 这次 | 状态 |
|---|---|---|
| H1 视觉本体感知（从 h_t 解码真实关节角，基线：开环命令积分、v1 迟滞辨识） | 合成数据上：比开环好 38%，但和随机 GRU 对照、方向记忆规则持平 | **未证实**；新增两个必须报的基线（随机 GRU、方向记忆规则）。v1 迟滞辨识（任务 11 的 `hysteresis_id.py`）用的是 K230 读数不是图像，没接进来；任务 11 报告里它的输出角估计误差是 0.03°，远好于这里所有方法——这说明结构化的迟滞模型目前遥遥领先 |

| 3.1 数据：自主探索 | 随机游走 + 爪子张合，不看画面 | 能用；真机可以直接照这个策略采 |

## 5. 真机图像上可能遇到的问题

1. **分辨率**：真机 K230 视场 ±35°，缩到 64×64 后每度不到 1 像素，回差 1° 只有 0.9 像素（合成数据特意用了 ±20° 视场，每度 1.6 像素）。
   真机要用 128 以上的分辨率，或者裁中间一块
2. **爪子太小**：真机爪子脚约占画面 1/60（合成数据约 1/35 都没分出来）。可能需要更多槽位、更高分辨率，或者用任务 10 的忽略区域做弱监督
3. **背景**：真机背景（平台、桌子、人）比合成纹理复杂得多，"一个槽位包住全图"的塌缩会更严重；光照变化、自动曝光也比 ±15% 大
4. **相机位姿不只由底座 + 升降决定**：真机伸出 / 抬起姿态时 2~5 号舵机都在动，动作特征要加上它们（或者只用观察姿态下的片段）
5. **运动模糊和时间对齐**：K230 约 7 帧/秒，动作中的帧有模糊；要用任务 12 的同步标记挑"动作结束、画面稳定后"的那张图，对齐误差会直接变成"假的回差"
6. **真值**：H1 需要电位器 ADC（方案 3.5 节），H2 需要人工标几十张掩膜；否则只能看平移预测损失这种间接指标
7. **算力**：这次 CPU 15 分钟/变体明显不够；真机图像更难，必须上 GPU（方案第 6 节的 ≥12GB 显卡）
8. **J 和回差会随时间变**（舵机磨损、负载），合成数据里每条序列固定；真机数据要按时间段分开评估

## 6. 和真机仿真的其他差别（合成数据的简化）
- 一台车的灵敏度 J 固定（底座 −1、升降 6mm/cm），只有回差 / 死区按序列变，方便按回差分组；真机标定的底座 J 约 −0.6
- 物块不旋转、没有阴影；背景对比度比第一版调低了（第一版槽位学不出来）
- 执行器的落点随机误差（`sim_world.EXEC_SIGMA`）、死区、回差规则和任务 11 一样；没有动作中的模糊（只取动作结束后的帧）
