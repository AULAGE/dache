# 任务 08：真机试验记录工具 `bench.py`

## 背景
真机测试时，程序自己报的"抓到了"不可信（2026-11-03 出现过多次"报成功但实际没抓到"）。调试需要**人工记录真实结果**，
并按物块位置统计，才能看出"哪里偏、偏多少"。现在是用户在纸上记，容易乱。

测试矩阵见 `docs/抓取与调试方案.md` 第 3.2 节：近/中/远 × 左/中/右 共 9 个位置，每个位置 2 次。

## 目标
写 `raspberrypi/grasp/bench.py`（树莓派上运行，用户在 SSH 终端里交互）：

1. **`python3 bench.py`**：按测试矩阵依次提示"把物块放到 ⑤ 中间·中（约 18cm、正前方）→ 回车开始"，
   然后调用 `main.py` 里真机运行同一套代码跑一次抓取（等价于 `--once`，`--no-chassis` 由参数决定，默认无底盘），
   结束后问用户：
   - 真的抓到了吗？`[y / n]`
   - 没抓到的话：爪子偏哪边？`[左 / 右 / 前 / 后 / 高 / 低 / 不知道]`、大概偏几毫米
   - 可选备注
   记录到 `logs/bench.csv`：时间、位置编号、程序结果（success/…）、真实结果、偏差方向和毫米、对准时测到的物块位置（x_deg/y/d）、
   底座角度、升降轴高度、抓取深度插值 t、当时的 `GRASP_BASE_TRIM_DEG`、步数、用时
2. **`python3 bench.py --positions 2,5,8`**：只跑指定位置；**`--repeat 3`**：每个位置次数
3. **`python3 bench.py report`**：
   - 按位置的 3×3 表：真实成功率、误报（程序说抓到但实际没有）次数
   - 偏差统计：按位置的平均偏差方向和毫米；如果某一方向的偏差在多数位置一致，**直接给出建议**
     （例如"多数位置偏右约 4mm → 运行 `calib.py trim 4`"；"只有右侧位置偏右 → 可能是底座回差，见任务 09"）
   - 程序结果 vs 真实结果的混淆表
4. 中途 Ctrl+C 能安全退出（升降轴急停、记录已完成的）；下次运行 `--resume` 从没测的位置继续

## 要求
- 复用现有代码：真机运行走 `main.py` 的 `open_devices` / `preflight` / `GraspTask.run_once`，**不要复制一份抓取逻辑**；
  需要的话可以小改 `main.py`（例如把"跑一次"抽成函数），但 `main.py` 现有命令行行为不能变
- 位置说明要具体（离车多远、往左/右多少度大概是多远），左右方向和 `config` 的约定一致（底座右转为正）
- 离线可测：`selftest.py` 里加测试（用 `sim.py` 的设备代替真机，用户输入用假的 input）
