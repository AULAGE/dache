# 任务 05：机械臂逆运动学（IK）

## 背景
机械臂是 Lobot 6 舵机臂（固件 `PWM机械臂/`）：1 爪子、2 腕部（K230 相机装在这一节）、3/4/5 臂、6 底座，脉宽 500~2500us。
现在抓取是"在两个标定姿态 `reach_near` / `reach_far` 之间按深度线性插值"（`task.py` 的 `grasp()`），
覆盖范围窄、需要底盘把物块送到固定距离。

固件里已经有一段角度换算（`PWM机械臂/USER/PCMsg.c` 开头的注释和 `AH_*` 函数，**GBK 编码**）：
```
T1=0.09*(p5-p4)+90, T2=0.09*p4+45, T3=225-0.09*p5     （内角，度；p = 舵机脉宽）
初始 (500,500,500)、最前伸 (1500,1500,2500)、最高 (500,1500,1500)、前下 (2500,500,2500)，p3+p4-p5=500
```
用户录下的一次真实抓取（树莓派 `~/arm.txt`，已写进 `config.py` 的 `POSES` 初值）：
初始 3:758 4:601 5:1185 → 伸出 3:758 4:714 5:1919 → 抬起 5:1275。

## 目标
1. 从 `PCMsg.c` 的换算关系 + 用户实测姿态，建立机械臂的正运动学模型（连杆长度用参数表示，**没有实测值**）
2. 写逆运动学：给定"物块在 observe 姿态相机坐标系下的位置（K230 测量值）"→ 求伸出抓取的 3/4/5 号舵机脉宽
   （腕部 2 号保持爪子竖直向下或水平，两种模式）
3. 加入工作空间检查（够不够得着、关节限位、自碰撞粗检）
4. 设计**标定方法**：用户量几个连杆长度 + 用 `calib.py teach` 采几个点 → 拟合模型参数（最小二乘）。
   给出 `calib.py` 新命令的实现（例如 `calib.py ik-fit`），采点数据存 `calib.json`
5. 在 `task.py` 里加开关 `GRASP_MODE = "interp" | "ik"`，默认 `"interp"`（现在的行为）；`"ik"` 时用逆解，
   仿真里也加对应的模型验证（无底盘时 IK 应该让可抓范围明显变大）

## 限制
- 没有实测连杆长度——全部做成参数，报告里列出**用户需要量的尺寸清单**（附示意图描述）
- 不改机械臂固件和 Lobot 协议
- 相机在腕部：observe 姿态下相机的位置/朝向也要进模型（外参），可以用标定数据拟合
