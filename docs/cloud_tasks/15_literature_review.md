# 任务 15：论文文献调研 + 创新点核查 + 投稿期刊分析

先读 `CLAUDE.md`、`docs/论文研究方案.md`（v2）、`docs/cloud_tasks/results/11_报告.md`。**只写文档，不改代码。**

## 目标
1. **系统文献调研**（用网络搜索，每篇都要能打开原文核实，**不能编造文献**；找不到原文的标注"未核实"）。覆盖：
   - 视觉-语言-动作模型、模仿学习（RT-2、OpenVLA、π0、ACT、Diffusion Policy 等）—— 重点：**对本体感知的依赖**
   - 世界模型（Dreamer 系列、TD-MPC 系列、视频预测类）
   - 机器人自我建模 / 自我识别（视觉自我模型、DIJE arXiv 2507.00446 等）
   - 物体中心表示（Slot Attention 及机器人上的应用）
   - 交互式感知、自监督机器人学习
   - 无标定视觉伺服、在线雅可比估计、舵机/齿轮回差的辨识与补偿
   - 低成本机器人学习（ALOHA、LeRobot/SO-100 等）、**无编码器/无本体感知**的机器人学习
   - 眼在手上相机的自遮挡
2. **创新点核查**：逐条对照 `docs/论文研究方案.md` 第 2、3 节的每个创新点，找最接近的已有工作，判断：已被做过 / 部分做过 / 没找到。
   被做过的给出调整建议（怎么改才仍有新意）
3. **投稿期刊分析**：方案里列的候选期刊 + 你认为合适的，给出：范围是否匹配、近两年类似主题的论文例子（核实过的）、
   审稿周期和篇幅要求（官网能查到的）、**分区以投稿前查最新 JCR/中科院分区为准**（只写查到的年份）
4. 产出一份**相关工作章节草稿**（中文，后面可以翻成英文），按主题分段、每段结尾写"本文的区别"

- `docs/论文相关工作草稿.md`
