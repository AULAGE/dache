# 云端任务

这些任务**都不需要硬件**，适合交给 Claude Code 云端会话长时间自动跑。
每个任务一个文件，把对应文件的内容（或者"请按 docs/cloud_tasks/0X_xxx.md 执行"）发给云端会话即可。

开始前云端会话会先读仓库根目录的 `CLAUDE.md`（项目结构、协议、编码规则、测试方法）。

## 给每个任务的通用要求

- 在新分支上做（例如 `cloud/01-param-search`），**不要直接改 main**，完成后开 PR 或者把分支推上来
- 改了 `raspberrypi/grasp/` 就必须跑 `python3 selftest.py`，全部 ✅
- 产出一份中文报告 `docs/cloud_tasks/results/0X_报告.md`：做了什么、数据、结论、**哪些还没在真机验证**
- 不改通信协议、串口、波特率；新功能用 `config.py` 开关控制，默认保持原行为
- STM32 源码是 GBK + CRLF，别转换编码和换行
