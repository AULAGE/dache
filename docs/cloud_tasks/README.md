# 云端任务

这些任务**都不需要硬件**，适合交给 Claude Code 云端会话长时间自动跑。
每个任务一个文件，把对应文件的内容（或者"请按 docs/cloud_tasks/0X_xxx.md 执行"）发给云端会话即可。

开始前云端会话会先读仓库根目录的 `CLAUDE.md`（项目结构、协议、编码规则、测试方法）。

| # | 任务 | 价值 | 规模 | 需要真机验证吗 |
|---|---|---|---|---|
| 01 | [控制参数自动搜索](01_param_search.md) | ★★★ 直接产出可用的 `calib.json` 推荐值 | 中（主要是跑仿真） | 结果要真机确认 |
| 02 | [仿真更真实](02_sim_fidelity.md) | ★★★ 让 01 的结果更可信 | 中 | 否 |
| 03 | [底盘固件分析](03_chassis_firmware.md) | ★★ 查清速度平滑、超时、回传字段，改进底盘驱动 | 小 | 改进要真机确认 |
| 04 | [K230 程序审查与提速](04_k230_review.md) | ★★ 帧率是整套系统的瓶颈 | 中 | **必须**真机确认 |
| 05 | [机械臂逆运动学](05_arm_ik.md) | ★★ 不用插值也能抓，范围更大 | 大 | 需要连杆尺寸 |
| 06 | [激光雷达避障探索（设计+仿真）](06_lidar_explore.md) | ★ 以后让车自己往前开去找 | 大 | 必须 |
| 07 | [机械臂最省力的上电姿态（静力学模型）](07_power_on_pose.md) | ★★ 上电不抖、不发热 | 中 | 必须；先填 `inputs/arm_params.json` |

**建议顺序**：02 → 01（先让仿真更真实，再在上面搜参数）；03 和 04 可以并行。05、06 等基本抓取调通后再做。

## 给每个任务的通用要求

- 在新分支上做（例如 `cloud/01-param-search`），**不要直接改 main**，完成后开 PR 或者把分支推上来
- 改了 `raspberrypi/grasp/` 就必须跑 `python3 selftest.py`，全部 ✅
- 产出一份中文报告 `docs/cloud_tasks/results/0X_报告.md`：做了什么、数据、结论、**哪些还没在真机验证**
- 不改通信协议、串口、波特率；新功能用 `config.py` 开关控制，默认保持原行为
- STM32 源码是 GBK + CRLF，别转换编码和换行
