# 任务 18：底盘联调预演 + 分步操作手册

先读 `CLAUDE.md`、`docs/cloud_tasks/results/03_报告.md`、`docs/抓取与调试方案.md` 第 4 节。

## 背景
无底盘抓取在调，**底盘（WHEELTEC 阿克曼）还没在自动抓取里联调过**，计划 11/6 上车，只有 1~2 天时间，9 日晚决定比赛用不用底盘。
已知：固件没有串口超时停车（树莓派 50 Hz 发、0.5 s TTL、退出发停车帧）；早期直走 100 mm 实际走约 145 mm，加了滑行模型后未复测；最小转弯半径 600 mm 是估计值。

## 目标
1. **代码路径审查**：`devices.WheeltecChassis` + `task.align` 里底盘相关分支（阿克曼边走边转、几何前馈 `base_after_move`、`BASE_LIMIT_BACKUP_MM`、搜索后退）在真机参数下的行为；
   用 `sim.SimWheeltec`（任务 03）跑有底盘场景：物块在车前 300~700 mm、左右 ±30°，统计成功率、步数、用时、底盘总里程、是否出现危险动作（倒车过远、转向打满持续）
2. **`chassis_test.py` 补全**（如缺）：架空测试（车轮离地，确认退出即停）、直走 ±100/±200 mm 精度测试（提示用户量尺子并输入实测值，自动拟合滑行时间常数并写进 `calib.json`）、
   打满方向走一段测最小转弯半径（提示用户量）、电压读数
3. **分步操作手册** `docs/底盘联调手册.md`：每一步的命令、预期现象、出问题时怎么判断和处理、安全注意（手放在急停/电源旁）、
   每一步的"通过标准"，以及**9 日晚"底盘用不用"的决策标准**
4. 如发现会导致危险动作的 bug，最小修复（单独提交）
