# 任务 06：激光雷达避障 + 探索（设计 + 仿真，不上真机）

## 背景
现在看不到物块时车不会往前开（没有避障，闭着眼开不安全）。仿真里"没找到"的全是物块在 90cm 外、K230 识别不到的情况。
树莓派上有用户以前写的 N10 激光雷达脚本（`~/livox_n10*.py`、`~/start_n10.sh`、`~/ldlidar_sl_ros2-master/`，**不在本仓库里**），
还装过 ROS2 和 SLAM（cartographer）。底盘是阿克曼转向（不能原地转，最小转弯半径见 `config.ACK_MIN_RADIUS_MM`）。

## 目标
1. **设计**探索策略：搜索不到物块时，在雷达保证安全的前提下往前/绕行探索，再搜索；有边界（最多走多远、多久放弃回原点）
2. **雷达接口**：定义 `devices.py` 里的 `Lidar` 接口（`scan() -> [(角度, 距离), ...]`、`nearest_in_sector(a1, a2)`），
   真机实现留桩并写清楚需要用户确认的东西（雷达型号/串口/协议——让用户把 `~/livox_n10*.py` 加进仓库后再实现）
3. **仿真**：在 `sim.py` 里加障碍物和模拟雷达；探索 + 抓取整套在仿真里跑通；统计"物块在 0.9~2m 外"时的找到率和碰撞次数（必须为 0）
4. 安全：任何时候前方（按车速和刹车距离算的）扇区内有障碍就停；雷达数据超时就停

## 限制
- 默认关闭（`EXPLORE = False`），关闭时行为和现在完全一样
- 不依赖 ROS（树莓派上 ROS 环境复杂，先做纯 Python）；如果认为用 ROS2 nav2 更合适，在报告里论证，不要直接引入
- 阿克曼运动学约束必须遵守

## 交付物
- `task.py` / `devices.py` / `sim.py` / `config.py` 改动（带开关）+ `selftest.py` 新测试（含"碰撞必须为 0"）
- `docs/cloud_tasks/results/06_报告.md`：策略、安全论证、仿真结果、**用户需要提供的信息清单**

## 验收
- `python3 selftest.py` 全部通过；`EXPLORE = False` 时行为不变；仿真碰撞次数 0
