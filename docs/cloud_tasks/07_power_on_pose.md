# 任务 07：机械臂最省力的上电姿态（静力学模型）

## 背景
机械臂控制板（`PWM机械臂/`，Lobot，STM32F103，**GBK 编码**）上电后、树莓派发指令之前，舵机停在固件
`USER/PWM.c` 里 `ServoPwmDuty[8]` 的初值。原固件是 3/4/5 = 500（收拢）。

真机现象（2026-11-03）：
- 4 号在 500 时**剧烈抖动**（顶到机械限位）；调到 **560 不抖了，但发热严重**、散热慢——说明仍在持续出力
- 1 号（爪子）也有轻微抖动
- 用 `arm.txt` 的工作姿态（3:758 4:601 5:1185）时不抖
- 舵机编号：1 爪子、2 腕部（K230 相机装在这一节）、3/4/5 臂、6 底座；脉宽 500~2500us

用户要的是：**尽量接近原来的收拢姿态，又不抖、静止时最省力（发热最小）**。

## 目标
1. 建立机械臂**静力学模型**：每个关节在某个姿态下要扛的重力力矩
   - 运动学参考 `PWM机械臂/USER/PCMsg.c` 开头的注释和 `AH_*` 函数（脉宽 ↔ 内角：`T1=0.09*(p5-p4)+90, T2=0.09*p4+45, T3=225-0.09*p5`）
   - 连杆长度、质量、K230 质量、舵机质量都做成参数，从 `docs/cloud_tasks/inputs/arm_params.json` 读（用户测量后填；没有这个文件就用报告里写明的估计值，并在结论里标"估计"）
2. 定义"耗能"：静止电流近似 ∝ 力矩（再加上顶限位的惩罚）。总代价 = Σ|τ_i| / τ_stall_i + 限位惩罚 + 偏离原收拢姿态的惩罚（权重可调）
3. 约束：每个舵机离用户测得的机械限位至少留余量（默认 60us）；不能自碰撞（粗检）；爪子不能顶死（开合都离限位 ≥ 60us）
4. 在约束内搜索（网格 + 局部优化都行），输出**前 3 个候选姿态**（每个舵机的脉宽）、各关节力矩、和原姿态的差别
5. 灵敏度：连杆长度/质量 ±20% 时前 3 名是否稳定
6. 再给一个"**上电不出力**"方案的评估：固件上电不输出 PWM，等第一条指令再输出（零耗能，代价是上电时臂会软下来）。
   在 `PWM.c` 里加编译开关 `POWER_ON_LIMP`（默认 0 = 原行为），实现：第一次收到 `CMD_MULT_SERVO_MOVE` 之前 TIM3 中断里不拉高引脚；
   并说明第一次动作时从软下来的位置跳到目标的风险和缓解办法（例如第一条指令用很长的动作时间）

## 限制
- 云端没有硬件、没有 Keil：固件改动只做最小改动、保持 GBK 编码和 CRLF（用 `open(..., encoding="gbk", newline="")`），新增内容只用 ASCII；
  能抽出来的逻辑用 gcc 在主机上编译测试
- 不改 Lobot 通信协议
- 不改 `ServoPwmDuty` 初值的默认值——把推荐值写进报告，由用户在真机验证后决定（或者加一个 `#define POWER_ON_POSE_xxx` 编译开关，默认保持原值）
