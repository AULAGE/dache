# 任务 14：世界模型原型——合成腕部相机图像上验证"学出本体感知"（论文 H1/H2）

先读 `CLAUDE.md`、`docs/论文研究方案.md`（v2，重点第 2、3.2、4 节）、`docs/cloud_tasks/results/11_报告.md`。

## 目标
在真机图像到手之前，用**合成图像**把论文核心模型的训练流程跑通，并回答：
- **H1**：只给"命令历史 + 图像"，模型的隐状态能不能线性解码出**真实舵机角**（含回差、死区），比"命令积分"准多少？
- **H2**：不给任何标注，模型能不能把画面分成"自身（爪子）"和"世界（物块）"？

## 内容（全部放在新目录 `raspberrypi/grasp/research/worldmodel/`，不改其他文件）
1. `render.py`：简单 2D 渲染器生成腕部相机画面（64×64 或 96×96 就够）
   - 物块：已知尺寸的彩色方块，位置由相机位姿决定（底座角、升降高度 → 画面位移，复用 `research/sim_world.py` 的执行器迟滞模型和几何）
   - 爪子脚：**固定**在画面左侧中间的一块形状（和相机固连），张爪/合爪两种形态
   - 背景纹理、光照变化、噪声、偶尔的干扰物；物块碰边缘、被爪子部分遮挡
2. `dataset.py`：自主探索策略生成 (o_t, u_t, o_{t+1}, 真实关节角, 真实掩膜) 序列；真值只用于评估
3. `model.py`（PyTorch）：
   - 编码器 + Slot Attention（K=3~4）+ 迟滞记忆 GRU（输入命令历史）+ 动作条件动力学 + 解码器（重建）
   - 自身/世界分离先验：自身槽位位移 ≈ 0 的正则；世界槽位位移由"相机运动"解释
   - 对照组：无分离先验、无 GRU（只用当前命令）、只用命令积分
4. `train.py` / `eval.py`：CPU 上能在 1~2 小时内训出可用结果（小图、小模型）；有 GPU 自动用
   - H1 指标：线性探针从 GRU 隐状态解码真实角度的误差（°），对比命令积分；按回差大小分组
   - H2 指标：槽位掩膜和真实"爪子 / 物块"掩膜的 IoU
   - 消融表
5. `README.md`：怎么跑、结果、以后换成真机图像（任务 12 的数据集格式）要改哪里

## 要求
- 只在 `research/worldmodel/` 下新建文件；依赖 `torch`、`numpy`（写进 `requirements.txt`，`selftest.py` 不依赖它们）
- 固定随机种子，可复现；训练日志和结果表存到 `research/worldmodel/results/`（不提交大文件，模型权重 ≤ 5MB 才提交）
- 报告 `docs/cloud_tasks/results/14_报告.md`：方法、结果表、失败的尝试、和论文假设的对应、**真机图像上可能遇到的问题**

## 验收
- `python3 research/worldmodel/train.py --quick` 在 CPU 上 10 分钟内跑完并输出指标
- `cd raspberrypi/grasp && python3 selftest.py` 原有测试全部通过
- 所有结论标明"合成数据"
